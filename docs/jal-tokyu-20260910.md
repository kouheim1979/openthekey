# JALカード TOKYU POINT ClubQ（2026-09-10）

本人確認：JALカード TOKYU POINT ClubQ、ショッピングマイル・プレミアム未加入。

通常200円税込につき1マイルとして登録。マイルを現金の0.5%と断定せず、1マイルの換算額を表示・変更できるようにした。初期換算は1円（JAL公式の10,000マイル→10,000 TOKYU POINT交換を参照）。他の換算額は比較用で、交換価値の保証ではない。JAL特約店倍付けは支店・ルート確認前に加算しない。

- サンマルクカフェ 港北東急SC店：支店として追加。TOKYU POINT通常税込1%を提示分として別表示。JALカード払いにもカード提示＋コード払いにも対象。一般TOKYU CARDのクレジットポイントは重ねない。
- サンマルクは施設公式の対象外・例外一覧に掲載なし。決済対応は施設・ブランド案内に基づく条件付き登録で、支店実機確認ではない。全国のサンマルクへ港北東急のポイント条件を適用しない。
- myサンマルクはクーポン交換型。1ポイント＝1円とは扱わず、TOKYUとの併用を未確認のまま合計しない。旧カフェアプリは2026-08-31終了。
- 港北東急SCの施設案内を追加。ロピア、セブン-イレブン、魚べい等の対象外と、シャトレーゼ等の別条件を明示。施設名だけでは個店の順位を確定しない。
- 東急ストアにも同じJALカード設定を追加。提携カードの加盟店ポイントは200円税抜につき1P。一般TOKYU CARDの3Pとは別。
- 日別のポイントアップキャンペーン、未確認の特約店倍付けは通常率に加算しない。
