# イオン・オーナーズカードの店舗別適用（2026-09-10）

ユーザーはオーナーズカード保有。返金率そのものは未確認のため、既存の保存設定と返金率セレクターを維持する。未設定の3%は仮設定と明記する。

## 店舗と決済を別々に判定

- 返金対象として登録：イオン、イオンスタイル、まいばすけっと、ダイエー、イオンフードスタイル、グルメシティ、マックスバリュ、ピーコックストア、ビッグ・エー、ザ・ビッグ。
- 上記は直営売場・対象商品の指定支払いに限定。今回ランキングに登録した対象ルートはAEON Payコード払いと現金。その他の支払いは未確認と非対応を区別する。
- 対象外の表示を追加：マルエツ、ミニストップ、ウエルシア、ハックドラッグ（ウエルシア薬局）。AEON Payの2倍特典やWAON POINT対応から優待対象を推測しない。
- ベルクは公式対象店舗一覧に掲載がない旨を表示し、優待返金を加算しない。
- まいばすけっと・ビッグ・エーは買物が対象でも返金引換証の換金窓口ではない。両者を混同しない。
- イオンモール・イオンタウンの施設名だけでイオン直営売場として照合しない。
- 返金対象の決済IDを店舗ごとの明示リストに限定。今後、未来屋書店・コックス・ジーフットの現金限定特典を登録する場合もAEON Pay対応とは独立して設定する。
- 株主優待、決済ポイント、提示ポイントは別枠。感謝デーの割引は日付だけで自動加算しない。優待をWAON POINTで受け取っても再度加算しない。
