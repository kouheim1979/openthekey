# 支払いチェッカー

公開先: https://kouheim1979.github.io/openthekey/

店名または現在地から店舗を選び、支払い方法を比較する静的アプリです。決済ポイントと、会計前に提示するポイントカードの特典を分けて表示します。

## 開発で維持する仕様

- ピンク・黄色・水色・緑、太い黒枠、ポップな影、「いまのお店、何で払う？」のデザインを維持します。配置や視認性の改善を理由に別のデザインへ変更しません。
- PayPayは比較設定1.5%。楽天ペイの条件達成時1.5%と同率ならPayPayを先に表示します。
- 楽天ペイと楽天ポイントカードは別表示です。提示ポイントを決済還元に含めたり、同じ進呈分を二重計上したりしません。税抜と税込の率も一律に合算しません。
- 三菱UFJカード対象店は比較設定12.5%、Olive対象店は対象方式で8%。実際の適用条件・対象方式を併記します。
- d払いは基本0.5%、dカード設定時は計1.0%、他社カード設定時はd払い自体0%。au PAY・FamiPayは通常0.5%。FamiPayバーコード、カード、QUICPayを混同しません。
- AEON Payは通常コード払い0.5%、所定の2倍対象店1.0%。イオンカードの対応だけではAEON Pay対応と判断しません。
- 未確認は非対応の断定ではありません。一方、未確認の支払いをおすすめ順位には入れません。支店・売場・レジ・商品による条件差を残します。
- 店舗更新は公式の決済対応、提示ポイント、還元率、支店差を確認し、出典をデータへ保存します。
- 横浜市都筑区、北山田〜センター北〜センター南で利用しやすい店舗を優先します。

## 構成

- `index.html`、`app-v2.html`、`app-v3.html`: 同一の現行画面。CSSの基調を保ち、3つを同期します。
- `audit-data-20260906.js`: 基本店舗データ。
- `local-stores-20260907.js`: よく使う店舗の追加データ。現在133店舗・ブランド。
- `location-search-20260907.js`: 任意の現在地サービス。位置取得・Overpass通信・短時間のメモリキャッシュを担当します。
- `checker-20260907.js`: 検索、ランキング、ポイント、画面表示。現在地サービスを読み込めなくても店名検索は動作します。
- `icons/payment-checker-v2.svg`: アプリアイコンの原本。既存の配色で支払いカードとチェックを描き、同名の32・180・192・512px PNGを書き出しています。タブ、iPhoneのホーム画面、ページ見出しで統一します。
- `manifest.webmanifest`: 静的なアプリ情報。アイコンとともにHTMLから直接読み込み、起動時の画像生成処理には依存しません。
- `legacy.html`、`checker-20260906.js`: 以前の実装を保持。

読み込み順は基本データ → 追加データ → 現在地サービス → チェッカー。すべて同じ公開コミットから配信します。スクリプトを変更したときは、3つのHTMLのSRI（SHA-384）とキャッシュ識別子を同時に更新してください。HTMLやJavaScriptを読み込んだ後の文字列置換で修正を重ねないでください。

## 現在地検索

初回は低消費電力の位置取得を優先し、誤差が大きい場合だけ精度を上げます。位置取得はアプリ側の時計で全体4.5秒まで、店舗通信は2接続先全体で5秒まで。遅い接続先には800ms後に予備を使い、不要な通信を中止します。これらはアプリの待機上限で、端末実機の測定結果ではありません。

直近30秒の位置と、範囲を覆う直近2分の店舗データをページ内メモリで再利用します。ページを閉じると消えます。店名検索・店舗選択・中止・ページ移動で処理をキャンセルし、遅れて届いた結果で画面を上書きしません。

## イオン株主優待

イオン・イオンスタイルの直営売場について、確認済みのAEON Pay・現金にのみ優待を加算します。決済分と優待分の内訳を表示します。返金率は1・2・3・4・5・7%から選択でき、今回は使わない（0%）にもできます。初期3%は仮設定と画面に明示し、選択後は端末の設定として保存します。株数を推測して確定しません。家族カードとの半年100万円枠や対象外条件は詳細に掲載しています。

マルエツ・ミニストップ・ウエルシア等へイオン優待を自動適用しません。マルエツのWAON POINTは税抜200円で1ポイントの提示分として別表示します。

## 確認と公開

```sh
node --check checker-20260907.js
node --check local-stores-20260907.js
node --check location-search-20260907.js
node --test tests/regression.cjs
```

テストは実際の配信スクリプトをDOM・イベントの代替環境と仮想時計で実行し、全店舗の表示、還元率、同率順、優待、位置取得失敗、通信遅延、キャンセル、キャッシュ、SRIを確認します。実機GPSやブラウザの見た目の確認とは区別してください。

公開用の変更は、最新mainを親にした1つのコミットへまとめます。他の更新を上書きする強制更新はしません。GitHubへの書き込み成功と、同じコミットの「pages build and deployment」完了を確認してから、公開済みと案内してください。
